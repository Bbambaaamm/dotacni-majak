# Typ finančního nástroje na detailu (#401)

Detail API čte `grant_call_versions.funding_instrument_type` i `funding_scenarios.instrument_type` z aktuální verze výzvy a vrací je jako `fundingInstrumentType` a `instrumentType`. V UI je typ podpory výslovně označen. Jen když jsou oba typy `GRANT`, zobrazují se grantové částky a míra podpory; `LOAN`, `GUARANTEE`, `EQUITY`, `MIXED`, `OTHER` i nesoulad obou typů nedostávají grantový výpočet ani popisek „Maximální dotace“. Negrantová výzva nemá ani CTA „Chci tuto dotaci“. Zůstává odkaz na samostatný doklad, pokud je v detailu dostupný; bez něj UI uvádí chybějící důkaz. Jde o prezentaci normalizované aktuální verze, nikoli o finanční model individuálního projektu. Konkrétní cash-flow, vlastní zdroje a vhodnost scénáře zůstávají nevyhodnocené; rozhodují podmínky poskytovatele.

Regrese: unit kontrakt Detail API pro typ `LOAN`; syntetická D1 fixture s negrantovým scénářem a scénářem `GRANT` v negrantové výzvě se záměrně vyplněnými grantovými poli testuje, že skutečné API typy zachová a mobilní browser žádné grantové číslo nevydá za úvěr či dotaci. Stávající čistě grantový scénář se nadále zobrazuje. Fixture není fakt o reálné výzvě.
