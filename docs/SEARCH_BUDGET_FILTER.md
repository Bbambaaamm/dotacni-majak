# Search API: doložený katalogový interval nákladů projektu (#400, dílčí slice)

Volitelný `GET /api/search?intent=…&projectBudgetCzk=150` přijímá celé nezáporné koruny CZK bez mezer, znaménka, desetinné tečky a úvodních nul (výjimka `0`). Hodnota má nejvýše 13 číslic a musí být bezpečně převoditelná na haléře. Chybná, prázdná či opakovaná hodnota vrací 400 `INVALID_PROJECT_BUDGET` před přístupem k D1. Cursor je svázán s hodnotou; starý cursor lze použít jen bez tohoto filtru. Žádné klientské ovládání v tomto dílčím API slice nevzniká.

Filtr zahrne jen aktivní indexovanou verzi typu `GRANT`, pro kterou existuje grantový scénář v CZK s oběma explicitními hranicemi `project_cost_min_minor` a `project_cost_max_minor`, včetně koncových hodnot. Scénář musí odkazovat na `VERIFIED` doklad právě k dané verzi a danému scénáři (`/funding_scenarios/<id>`), jehož dokument patří téže výzvě. Neznámá byť jediná hranice, chybějící/neshodný nebo neověřený doklad, jiná měna, úvěr a rozpor typů jsou v tomto filtru vyloučeny; nejsou vyhodnoceny jako nezpůsobilost. Více scénářů znamená existenci aspoň jednoho doloženého odpovídajícího scénáře, nikoli potvrzení, že konkrétní žadatel jeho podmínky splňuje.

Podmínka se uplatňuje před stránkováním v přímé i ontologické FTS fázi, při relevanci i obou datových řazeních. Bounded facety ji respektují, avšak limit 500 nezfiltrovaných FTS ID stále platí; nad limitem je `facets:null`. Částka není výše dotace, potřeba vlastní hotovosti, míra podpory ani osobní způsobilost. Před rozhodnutím je nutné ověřit oficiální podmínky, datum a projektové náklady. Navazující UI a skutečný browser-visible E2E zůstávají otevřené v #400; samotný API slice je ověřen real D1 testem, nikoli mock databází.
