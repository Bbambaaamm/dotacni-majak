# v1.0 known limitations register — template

Pro konkrétní release candidate vytvořte seznam pouze skutečných omezení.
Příklady kategorií:

- source coverage,
- source freshness,
- unsupported applicant/project edge cases,
- UNKNOWN extraction fields,
- accessibility limitations,
- browser/PWA limitations,
- notification limitations,
- data retention/recovery limitations.

Každé omezení musí mít:
- anonymní ID,
- stručný dopad,
- komu se týká,
- workaround, pokud existuje,
- zda je veřejně komunikováno,
- explicitní risk acceptance pro release.

„Nemáme žádné známé omezení“ je potřeba doložit review, ne předpokládat.
