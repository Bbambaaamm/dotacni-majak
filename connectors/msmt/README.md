# MŠMT / OP JAK connectors

Balíček obsahuje dva samostatné Source Adapters.

## MSMT
Oficiální centrální katalog:
https://msmt.gov.cz/dotace

Extrakce:
- stav dotace,
- typ projektu,
- cíloví/oprávnění žadatelé,
- deadline z textu,
- oficiální PDF/DOCX/XLSX přílohy.

Doplňkové články typu „Dodatek“, „Seznam podpořených…“ nebo výsledkové články se nepovažují za samostatné GrantCall.

## OPJAK
Oficiální katalog:
https://opjak.cz/vyzvy/

Extrakce:
- kód výzvy,
- otevření/uzavření,
- alokace,
- cíl výzvy,
- oprávnění žadatelé,
- způsob podání,
- text výzvy / přílohy / pravidla.

## Safety
Oba adaptéry jsou RAW-first, nepovažují zmizení ze seznamu za zrušení a mají samostatný Source Health.
