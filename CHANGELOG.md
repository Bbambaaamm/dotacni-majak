# Changelog

Veřejný changelog Dotačního majáku. Uvádí pouze změny, které jsou skutečně součástí `main`.

## 2026-09-23

### Přidáno
- regionální konektory pro Prahu, Plzeňský, Karlovarský a Jihočeský kraj,
- veřejná stránka Pokrytí Majáku se stavem zdrojů,
- historická data ReD a model podobných podpořených projektů,
- explainable hybrid search, eligibility a finance engine,
- application workspace, watches a notifications,
- bezpečné zpracování dokumentů a source health monitoring.

### Bezpečnost a důvěryhodnost
- RAW-first ingestion,
- immutable versioning výzev a dokumentů,
- provenance u kritických údajů,
- quality gate proti destruktivním změnám při rozbitém zdroji,
- GuardedHttpClient s SSRF ochranou,
- disappearance není automaticky CLOSED/CANCELLED.

## 2026-09-22

### Založeno
- projekt Dotační maják,
- značka **Najde. Pohlídá. Dotáhne.**,
- canonical schema, Source Adapter Contract a zero-cost-first architektura.
