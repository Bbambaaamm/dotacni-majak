# Design System v1

## Priority
Srozumitelnost → důvěra → další krok → estetika.

## Barvy
- Navy: #0B2D48
- Teal: #087F8C
- Cyan: #20B8CD
- Ink: #17212B
- Page: #F8FAFC
- Border: #DCE4EA
- Success: #16865C
- Warning: #A86100
- Error: #C83E4D

Stav nikdy pouze barvou.

## Typografie
Inter, fallback system-ui. Tabular numerals pro finance.

## Spacing
4px grid; hlavní škála 4/8/12/16/24/32/48/64/96.

## Povinné komponenty
- Intent Search
- Grant Card
- Eligibility Status
- Evidence/Provenance
- Next Action
- Finance Summary
- Project Watch
- Comparison
- Application Workspace
- Change Diff
- Source Health
- Loading/Empty/Error states

## UX pravidlo
Každá klíčová stránka musí odpovědět: **Co mám udělat teď?**

## Accessibility
WCAG 2.2 AA foundation, keyboard, focus, semantic HTML, text+icon+barva, 200% zoom, reflow, reduced motion, screen-reader testy.
